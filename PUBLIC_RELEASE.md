# Public release provenance

This repository starts from the audited webClx 1.8.11 source snapshot. The
application source corresponds to `SOURCE_RELEASE` commit `eae65b782b67`.
The first public Git commit only replaces repository URL placeholders and adds
public release metadata.

The original versioned archive and its SHA-256 checksum are attached to the
GitHub `v1.8.11` release. Verify the archive before building it.

Internal agent configuration, cross-model execution records, runtime
credentials, local settings, terminal history, remote deployment scripts,
build output, and the private development Git history are intentionally
excluded from the public source release.
