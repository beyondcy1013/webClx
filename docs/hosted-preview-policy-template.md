## 需要经营者填写

- 服务提供者：`SERVICE_PROVIDER`
- 联系邮箱：`SUPPORT_EMAIL`

## 服务范围

webClx 隔离托管预览为受邀用户提供一个独立的远程开发工作台实例，包括约定的计算资源、工作区、TLS 入口、webClx 版本更新、备份和工作日尽力支持。它是开发者预览，不是零停机托管平台，不提供未经书面约定的可用性 SLA。

模型 API、Codex、Claude、DeepSeek Harness 及其它第三方服务由用户自行订阅并遵守其条款。服务提供者不销售、共享或代充第三方模型账号。用户应在自己的隔离实例中配置凭据，不应通过聊天、邮件或工单发送密钥。

## 试用、计费与续费

- 受邀试用期为 7 天，除非邀请中另有书面说明。
- 试用不默认转为付费，也不默认续费；到期前会提供付费、导出或删除选择。
- 套餐价格、资源上限、账期和第三方资源费用以订单为准。
- 任何超出套餐的资源或人工服务都应先报价并由用户确认，不以“无限”描述服务。

## 退款

- 首次购买后 7 天内可以申请退款。
- 已实际发生且在购买前明确披露的第三方资源费用，可从退款中扣除。
- 商业许可、定制开发、迁移和已经完成的一次性专业服务按书面订单处理。
- 退款渠道、处理时限和收据冲销方式由 `PAYMENT_AND_RECEIPT_METHOD` 补充。

## 收集和处理的数据

为了申请、开通、保障和结算服务，预览期可能处理：

| 数据 | 用途 | 默认保留 |
| --- | --- | --- |
| 邮箱、地区、用途、Harness 和预计存储 | 审核申请与选择资源 | 申请拒绝或撤回后 30 天 |
| 订单、付款和退款记录 | 对账、收据和争议处理 | 按适用财税要求确定 |
| 实例标识、版本、资源使用和管理操作记录 | 运维、安全审计和成本核算 | 服务结束后 90 天 |
| 必要的服务错误日志 | 故障定位和安全响应 | 滚动保留 30 天 |
| 用户工作区和备份 | 提供远程工作台与恢复 | 按下述导出删除流程 |

日志不应记录密码、Cookie、模型 API key、本地自动化令牌或会话密钥。服务提供者不会将客户代码或终端内容用于训练模型，也不会主动读取工作区内容；只有在用户明确请求支持且给出范围时，才进行最小必要访问并记录操作。

## 隔离和安全边界

每位无关客户使用独立的 OS 用户、应用目录、服务、监听端口、工作区、配置、凭据、制品目录和备份。公网入口使用独立 TLS 主机名，源端口由防火墙限制。

用户负责保护自己的登录凭据、模型凭据和终端内容，并应及时报告异常。webClx 可以运行命令和修改文件，误操作、恶意依赖及第三方模型输出仍可能造成损失；重要数据必须保留独立副本。

## 可接受用途

不得使用服务侵入未授权系统、传播恶意软件、侵犯知识产权或隐私、规避第三方平台限制、进行违法活动，或故意消耗影响其他隔离实例的资源。遇到明确安全风险或法律要求时，服务可被临时暂停；除紧急情况外会尽力先通知并提供导出机会。

## 支持和事故

- 预览期支持时间：工作日，具体时区与响应目标由订单注明。
- 基础版不承诺固定响应时限；专业版目标为一个工作日内首次响应。
- 安全事件通过 `SUPPORT_EMAIL` 报告。确认影响客户数据后，将说明已知范围、处置和建议的凭据轮换步骤。
- 不使用“7x24”“绝对安全”“100% 可用”或未经审计的合规认证作为宣传。

## 导出、停用和删除

1. 试用或付费服务结束前 48 小时提醒用户选择续费、导出或删除。
2. 未续费实例进入 7 天只读导出期；期间停止执行新的 Agent 和部署任务。
3. 导出内容及交付方式由双方确认，默认只包含用户工作区，不包含服务器级密钥或其它客户数据。
4. 导出期结束后删除运行实例和在线工作区。
5. 备份在 30 天内完成轮换删除；法律要求保留的订单或审计记录除外。
6. 删除完成后向用户发送确认。需要提前删除可联系 `PRIVACY_EMAIL`。
