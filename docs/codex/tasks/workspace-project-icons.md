# 工作区项目图标

## 当前行为

- “设置 → 外观”分别保存工作区浏览图标和活动终端图标的项目相对路径。
- 工作区浏览默认读取项目根目录的 `icon.ico`，只对当前目录行做精确查找。
- 活动终端默认读取 `static/favicon.svg`；终端位于子目录时，从当前目录向上使用最近匹配的项目图标。
- 图标通过 `/api/workspace-icon` 返回，限制为 ICO、SVG、PNG、WebP、GIF、JPEG，最大 2 MB。
- 绝对路径、`..`、不支持的扩展名以及逃出项目的符号链接会被拒绝。

## 展示入口

- 工作区文件表：独立“图标”列。
- 工作区与活动终端选择器：图片位于终端文本之前；原生 `select` 继续作为值与 `change` 事件的状态源。
- 图文菜单挂载到页面级浮层并按触发按钮定位，避免被终端控制栏等横向滚动容器裁剪。
- 菜单使用不透明主题背景，鼠标悬停、键盘聚焦及当前选中条目均显示主题强调背景。
- 图片不存在时显示稳定的双字符项目文本图标与项目色；映射依据项目路径而非终端名，因此同一项目的根目录与子目录终端保持一致。
- 文本图标颜色先按项目键排序去重，再按黄金角依次分配色相；同项目共享颜色槽，不同项目不会落到相邻的近似色。

## 下拉菜单裁剪排查

- 如果当前项和图标可见、点击后 `aria-expanded="true"` 且菜单 `hidden=false`，但列表未出现，应检查祖先的 `overflow`，而不是先排查选项数据。
- 终端控制栏需要横向滚动，其纵向裁剪会截断普通绝对定位菜单；菜单因此不能放在选择器祖先内部。
- 浏览器回归必须在带滚动控制栏的真实布局中确认控制栏下方能命中菜单选项，孤立组件测试不足以覆盖此问题。

## 相关文件

- 设置模型：`crates/settings_core/src/*`
- 图片接口：`src/filesystem.rs`、`src/routes/workspace.rs`
- 公共前端组件：`static/workspace-project-icons.js`
- 页面接入：`static/app-workspace-browser.js`、`static/app-session-controls.js`、`static/terminal-session-render.js`

## 部署提醒

新脚本和样式必须随 `static/` 整体同步到 `/home/bin/webclx/static/`；仅替换二进制不会更新运行页面。
