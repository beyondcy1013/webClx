# Support

- Questions and deployment discussion: [GitHub Discussions](https://github.com/beyondcy1013/webClx/discussions)
- Reproducible bugs: [Bug report](https://github.com/beyondcy1013/webClx/issues/new?template=bug-report.yml)
- Product ideas: [Feature request](https://github.com/beyondcy1013/webClx/issues/new?template=feature-request.yml)
- Hosted trial: [Trial request](https://github.com/beyondcy1013/webClx/issues/new?template=hosted-trial.yml)
- Private security reports: use GitHub's **Report a vulnerability** action described in [SECURITY.md](SECURITY.md)

Do not post passwords, session cookies, API keys, private repository URLs, terminal output containing secrets, or customer data in Issues or Discussions.
